# План 1 этажа: растр → вектор (DXF/DWG)

Исходник `План 1 этажа.pdf` содержит **только растровое изображение** (скан БТИ,
2463×3095 px, ~150 dpi, разрезан на 11 полос) — векторных данных в нём нет.
Поэтому файл был обработан трассировкой растра в вектор.

## Файлы

| Файл | Назначение |
|---|---|
| `План 1 этажа.dwg` | **DWG R2000** — итоговый чертёж (масштаб 1:200, единицы — мм) |
| `План 1 этажа.dxf` | Тот же чертёж в DXF R2018 (на случай проблем с DWG: открыть в nanoCAD/AutoCAD и «Сохранить как → DWG») |
| `plan_1_floor_raster.png` | Растр-подложка. Должен лежать рядом с DXF/DWG — это гарантия «ничего не потерялось» |
| `Превью — сверка оригинал-вектор.png` | Визуальная сверка растра и вектора |
| `План 1 этажа.pdf` | Исходный PDF |
| `scripts/vectorize.py` | Скрипт пайплайна (воспроизводимость, актуальная версия) |
| `tools/` | Альтернативный пайплайн и QA-скрипты (покрытие, сверка, рендер) |

## Слои чертежа

- `A-PLAN-GRAPHICS` — вся чёрная графика: стены-контуры, перегородки, текст,
  размеры, оси, штамп (замкнутые полилинии по границам штрихов).
- `A-WALLS-FILL` — серая заливка несущих стен (HATCH, как в оригинале).
- `A-WALLS-OUTLINE` — контур заливки стен.
- `A-RASTER-UNDERLAY` — исходный скан (подложка; выключите для чистого вектора).
- `SHEET-FRAME` — рамка листа (граница страницы PDF).

## Геометрия и масштаб

- Скан выровнен (перекос 0.00°), система координат — **реальные метры в мм**
  по штампу **М 1:200**: 1 px скана = 33.87 мм натуры.
- Лист в натуральных размерах: ~86.4 × 111.8 м.
- ⚠️ Рекомендуется проверить размер: на плане есть габаритный размер
  **97.15 м** (длинная сторона) — измерьте его командой `_DIST` и при
  необходимости выполните `_SCALE` с опорным отрезком (погрешность размещения
  скана в PDF может дать отклонение до ~1–2%).

## Что важно знать

- Текст/размеры стали **векторными контурами** (не редактируемый текст) — это
  сознательное решение: при трассировке скана так сохраняется 100% графики.
- Контроль качества: 97.6% пикселей краски покрыто вектором (±1.5 px),
  потерь больше 20 px нет; все 3407 полилиний + штриховка + подложка
  подтверждены обратным чтением DWG→DXF.
- DWG записан в формате R2000 (AC1015) — открывается AutoCAD, nanoCAD,
  BricsCAD, LibreCAD и др.

## Пайплайн (воспроизведение)

1. PyMuPDF — извлечение и склейка растровых полос из PDF.
2. OpenCV — разделение на чёрную графику (<150) и серую заливку стен (~200),
   очистка гало антиалиасинга.
3. potrace — трассировка битмапов → сглаженные контуры Безье.
4. RDP-упрощение полилиний, ezdxf — сборка DXF (слои, подложка, мм, 1:200).
5. LibreDWG `dxf2dwg` — конвертация DXF → DWG R2000.

```bash
pip install pillow numpy opencv-python-headless pymupdf potracer ezdxf matplotlib
python3 scripts/vectorize.py
dxf2dwg "План 1 этажа.dxf"   # GNU LibreDWG ≥ 0.13
```
